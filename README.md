# retoPrincipiosProgramacion

🚗 AutoCare AI
AutoCare AI es una aplicación web desarrollada con Streamlit, PostgreSQL y Google Gemini que ayuda a los propietarios de vehículos a obtener orientación sobre posibles problemas mecánicos y recomendaciones de mantenimiento mediante inteligencia artificial.

Características
Consulta de síntomas en lenguaje natural.
Recomendaciones de mantenimiento preventivo.
Diagnóstico preliminar basado en IA.
Gestión de información de vehículos.
Historial de consultas.
Tecnologías
Python
Streamlit
PostgreSQL (Supabase)
SQLAlchemy
Google Gemini 3.5 Flash
